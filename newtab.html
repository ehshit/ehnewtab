theme

how to write it

anything that you write here will apply, any css is also saved as a backup, the root is html[data-theme="custom"].

html[data-theme="custom"] .clock { color: var(--pink); }
.hero { gap: 2rem; }
.search { border-color: var(--pink-mid); }
:root { --dim: 0.55; }

variables: --text, --text-dim, --text-muted, --bg, --bg-alt, --border, --border-hi, --pink, --pink-mid, --blue, --mint, --purple, --yellow, --cream, --font-syne, --font-mono, --radius, --radius-sm, --scrim-rgb

classes: .topbar .brand .navlink .shell .hero .clock-block .clock .date .search .engine .engine-display .q .go .attr .settings .settings-tab .settings-pane .panel-treatment .seg .btn .hint .toast

search position is exposed as html[data-search-pos="center"] or html[data-search-pos="non-center"]; clock position as html[data-clock-pos="center"] or html[data-clock-pos="non-center"]; box position as html[data-hero-pos="center"] or html[data-hero-pos="non-center"].
